# Xenon Studio Docs

:::note[Draft]
Paperkraft wrote this from your company's website and setup answers. Check it, then remove this note.
:::

Xenon Studio is an AI technical writer for software teams. Its agents turn product changes into updated docs, help articles and guides, ready for your team to review and publish. These docs cover what each agent does, how to connect your tools, how review and merging work, and how to fix problems when a change does not look right.

These docs are for Everyday users of the product.
