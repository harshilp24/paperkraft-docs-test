# Quickstart

:::note[Draft]
Paperkraft wrote this from your company's website and setup answers. Check it, then remove this note.
:::

1. Sign in to Xenon Studio and create a workspace.
2. Connect the tools your team already uses, such as your docs repository and your help centre.
3. Point Xenon Studio at the docs site you want it to keep current.
4. Ask for a change from a thread, a pull request or a ticket, or let an agent pick up a merged change.
5. Review the change it opens and approve it, or edit it first.
6. Check the weekly digest to see what changed in your docs.
